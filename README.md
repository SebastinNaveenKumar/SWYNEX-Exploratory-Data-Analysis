# SWYNEX – Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on telecom customer data using Microsoft Excel.

## Objectives
- Analyze telecom customer data.
- Summarize customer churn patterns.
- Explore monthly usage trends.
- Identify potential anomalies and useful insights.
- Present findings using Excel analysis and PivotTables.

## Tools Used
- Microsoft Excel
- PivotTables
- Data Analysis and Visualization

## Datasets
1. Customer Churn Labels
2. Telecom Usage Data
3. Exploratory Data Analysis Workbook

## Key Findings
- Analyzed 10,000 customer churn records.
- Identified 786 customers with a churn label of 1.
- Identified 9,214 customers with a churn label of 0.
- Calculated the overall churn proportion from the available churn labels.

## Files Included
- `SWYNEX_Exploratory_Data_Analysis.xlsx`
- `SWYNEX_Usage_Data_EDA.xlsx`
- `SWYNEX_cleaned_churn_labels.xlsx`

## Outcome
This project demonstrates data analysis, data summarization, and exploratory analysis skills using Microsoft Excel.
